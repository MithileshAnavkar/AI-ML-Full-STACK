## 🚀 Mini Project — Student Marks Analyzer

A beginner-friendly Python program that analyzes student marks stored in a dictionary.

### Features

* Calculates total marks
* Calculates average marks
* Finds highest marks
* Finds lowest marks
* Counts passed subjects
* Counts failed subjects
* Finds the subject with the highest marks

### 🛠️ Concepts Used

* Python dictionaries
* `for` loops
* `if/else` conditions
* `.items()`
* Variables
* Counters
* Basic problem-solving logic

## ▶️ How to Run

```bash
python day10_student_marks_analyzer.py
```
